# SCP Text-Based Game

## A Fun little side project for me to practice my C programming

## Notes

- This is *not* meant as an "actual" full game; rather, it is meant to be a framework into which I *could* slot a game. I am not a game designer, and this is not a game design side project. It's a programming project, so I will be stopping once I've implemented the mechanics I feel like implementing, and have a small demo put together.

## For Players:

To install and play the game:

1. Go to the latest Release in the right-hand side of the GitHub screen
2. Download `scpgame.zip` from the release files
3. Extract the zip file
4. Go into the directory where you extracted to
5. Play the game by running `./scpgame`

### System Requirements

- Operating System and architecture: Linux x86-64
- CPU: Potato
- Memory: Lemon
- Disk space: Less than 1 MB

## For Devs/Builders:
